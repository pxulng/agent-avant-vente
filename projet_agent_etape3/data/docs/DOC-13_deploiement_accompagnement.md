# [DOC-13] Déploiement et accompagnement

## Mise en route autonome
- Assistant de configuration : import des contacts, du catalogue et des modèles de devis.
- Durée typique de configuration autonome pour une équipe de moins de 10 utilisateurs : 1 à 3 jours.
- Données de démonstration disponibles pour tester.

## Accompagnement
- Pack d'accompagnement payant de 2 jours (configuration et formation en visioconférence) : 2 400 € HT, disponible sur toutes les offres.
- Migration de données assistée par les équipes de Brevaro : offre Entreprise uniquement, sur devis.
- Webinaires de formation collectifs, gratuits, toutes les semaines.

## Ce qui n'est pas inclus
- Installation sur les serveurs du client (« on-premise ») ou cloud privé dédié : non.
- Formation sur site : non.
- Environnement de recette distinct de la production : non (le bac à sable de l'API, DOC-09, ne concerne que l'API).
